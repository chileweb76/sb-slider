Screenshots and plugin assets for WordPress.org listing

- Place screenshots in this folder using the naming convention `1.png`, `2.png`, etc.
- For high-resolution images, add `1-2x.png`, `2-2x.png`, etc.
- WordPress.org uses the `assets/screenshots/` directory when the plugin is hosted in the SVN repo; when uploading a ZIP, include these files in the ZIP if you want screenshots displayed on wordpress.org.
